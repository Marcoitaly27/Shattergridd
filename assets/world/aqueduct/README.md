# Ruined aqueduct and embedded fossil

Original Blender-authored geometry, generated by `scripts/art/build_aqueduct.py`
using mesh helpers from `build_cloister.py`. No downloaded assets, paid services
or new third-party attribution obligations. Existing repository licensing is
unchanged. Rebuild with Blender --background --python scripts/art/build_aqueduct.py.

Five monumental arch bays with stone piers, an interrupted water channel and
rubble underneath the breach. A single oversized fossil bone emerges from low
masonry beside the cathedral; its exact creature is intentionally unspecified.
Two material batches; Godot mesh LODs enabled; no collision, lights or game logic.
Original art remains relatively regular and procedural, not a photogrammetry asset.
